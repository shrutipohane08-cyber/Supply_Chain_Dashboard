📊 Supply Chain Analytics Dashboard (Tableau)

📌 Project Overview

This project is an interactive Tableau Supply Chain Analytics Dashboard developed to provide end-to-end insights into order and delivery performance, supplier performance, inventory health, and overall business performance. The dashboard helps stakeholders monitor important supply chain KPIs, identify operational issues, and make data-driven decisions.

🎯 Objectives

Analyze overall supply chain performance.

Monitor order and delivery efficiency.

Track on-time delivery, processing time, delays, and order cycle time.

Analyze inventory levels, stock on hand, reorder levels, and warehouse capacity.

🎛️ Tableau Interactivity

Interactive filters for month, city, category, customer segment, delivery status, and supplier.

Top N supplier filtering for focused supplier analysis.

Dashboard actions allow users to explore information interactively.

Charts and KPIs update dynamically based on selected filters.

Users can drill into different dimensions of the supply chain from a single dashboard.

📌 Business Insights

Revenue and profit can be monitored from a single executive dashboard.

Carrier-level analysis helps identify delivery delays and processing issues.

Supplier reliability varies across countries and supplier tiers.

Inventory is concentrated in specific regions, helping identify stock distribution patterns.

Warehouse capacity analysis helps identify high-capacity locations.

Customer segments can be compared based on revenue and customer count.

Monthly trends help identify changes in revenue, orders, delivery performance, and inventory.

🚀 How to Use

Download or clone the repository.

Open the Tableau packaged workbook (.twbx) in Tableau Desktop.

Refresh the data source if required.

Navigate through the four dashboards.

Use filters and dashboard interactions to explore the data.

Analyze KPIs, charts, trends, and business insights.

📚 Dataset

The Supply Chain dataset contains information related to orders, customers, products, suppliers, warehouses, inventory, delivery, shipping, revenue, cost, customer segments, and supplier performance. The project covers order data from 2023–2024 and inventory snapshots for 2024.

⭐ Project Highlights

This project demonstrates the ability to transform supply chain data into an interactive Tableau business intelligence solution. It covers the complete supply chain cycle: Orders → Delivery → Suppliers → Inventory → Executive Insights. The dashboards help stakeholders quickly identify delivery problems, supplier performance issues, inventory conditions, revenue opportunities, and overall supply chain health.
